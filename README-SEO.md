# Wheaterflow SEO-bundel

Deze bundel bevat:
- `robots.txt`
- `sitemap.xml`
- indexeerbare landingspagina's voor Oostende, Brugge, Brussel, regenradar, waarschuwingen en kustweer
- `SEO-HEAD-SNIPPET.html` met metadata voor de bestaande `index.html`

## GitHub
Upload de mappen en bestanden naar de root van de Wheaterflow-repository, met behoud van de mapstructuur.

Voeg daarna de inhoud van `SEO-HEAD-SNIPPET.html` direct onder `<head>` in de bestaande `index.html` toe.

## Daarna in Google Search Console
Voeg `https://wheaterflow.be/sitemap.xml` toe als sitemap en vraag indexering aan voor de belangrijkste pagina's.
