VEELGESTELDE VRAGEN

Goed om te weten

Kan ik nu al echt betalen?

De checkout is volledig voorbereid, maar live betalingen staan bewust nog uit. Koppel later bijvoorbeeld Stripe, Mollie of een andere provider via een backend.

Kan ik later productfoto’s toevoegen?

Ja. Iedere productkaart heeft nu een vaste mediazone. Een echte afbeelding kan later met één veld per product worden ingevuld.

Werkt het winkelmandje na een refresh?

Ja. Het mandje wordt lokaal in de browser opgeslagen via localStorage.

Kan dit in wheaterflow.be geïntegreerd worden?

Ja. De map is bewust standalone gebouwd en kan bijvoorbeeld onder /shop/ of /webshop/ in de bestaande Wheaterflow-site geplaatst worden.
